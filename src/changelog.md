# About

Cyclone Simulator is a web-based simulation experiment aiming to visualize the life cycles of weather events namely tropical cyclones.

## Rewritten in Typescript

This changelog covers alpha/beta stages for the new edition of Cyclone Simulator (ultimately v1.0), rewritten from scratch in Typescript. Version history for the original edition (v0.x) can be found linked from its respective page.


# Changelog

## Alpha v1.0 (2026-11-20)

* Initial release of the new edition of Cyclone Simulator, a ground-up rewrite in Typescript, as Cyclone Simulator Alpha
* Includes:
    * A map (NASA blue marble) that can be panned and zoomed either by mouse or touchscreen
    * Rudimentary GUI in the form of a collapsible panel with buttons
    * Basic and very unrealistic test simulation
    * Run/Pause of the simulation via button or spacebar
    * Clock displaying in-universe date currently with zero effect on the simulation
    * Rotating storm icons that can be selected by mouse or touchscreen
    * Spawning storms via button to begin spawn then a click on the map to place
    * Test name list from the 1950 Atlantic hurricane season
    * Camera-follow of selected storms when the simulation is running
    * Appropriate links to this changelog and back to Cyclone Simulator Classic (v0.x)
    * The Debug Button
