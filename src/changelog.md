# About

Cyclone Simulator is a web-based simulation experiment aiming to visualize the life cycles of weather events namely tropical cyclones.

## Rewritten in Typescript

This changelog covers alpha/beta stages for the new edition of Cyclone Simulator (ultimately v1.0), rewritten from scratch in Typescript. Version history for the original edition (v0.x) can be found linked from its respective page.
